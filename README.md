# The Dreamer's Garden 🌷
### Between Dreams & Lines

**The Dreamer's Garden** is a dreamy, botanical-inspired poetry website designed to create a calm and immersive space for readers to explore poetry, emotions, and self-expression.

## ✨ Features

- **Poetry Collection:** Explore original poems in a clean, elegant layout.
- **Poem Reading:** Read poems in a dedicated, distraction-free view.
- **Category Filters:** Browse poems by theme or category.
- **Random Poetry:** Discover an inspiring poetic line.
- **Favorites:** Save your favorite poems for easy access.
- **Responsive Design:** Enjoy the experience on desktops, tablets, and mobile devices.
- **Light/Dark Mode:** Switch between themes for a comfortable reading experience.

## 🎨 Design Inspiration

The website uses a soft pastel palette featuring lavender, dusty pink, sage green, and warm cream. Botanical details, gentle typography, and a literary aesthetic bring the idea of a dreamer's garden to life.

## 🛠️ Tech Stack

- **React** — Component-based user interface
- **Vite** — Development server and build tool
- **HTML5** — Website structure
- **CSS3** — Styling, animations, and responsive layouts
- **JavaScript** — Interactive features

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd the-dreamers-garden
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Build for Production

```bash
npm run build
```
